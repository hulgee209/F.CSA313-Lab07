## Аппын тойм

Тестийн бай нь багшаас өгсөн «Уншлагын жагсаалт» веб апп. Энэхүү ажил нь SBTM charter, exploratory session-ийн тэмдэглэл болон олдсон согогуудын дахин гаргах алхмуудыг баримтжуулах зорилготой.

## Session-ийн дүгнэлт

60 минутын session-д 17 шалгалт хийж, таймерийг тасралтгүй ажиллуулсан бөгөөд саад гараагүй. Supermodel аяллаар эхний жагсаалтын тоолуур, оны формат, хайлт, устгалын мессеж болон хуучин хувилбарын холбоосыг ажиглав. Couch Potato аялал хамгийн үр дүнтэй байж, хоосон/дутуу талбар, 999, 2101 болон бүхэл бус оныг апп зөвшөөрч байгааг илрүүлэв. Ижил гарчиг, зохиолчтой номыг давхар нэмэхэд мөн хориглоогүй. Saboteur аяллаар буруу JSON POST хүсэлтэд HTTP 400 бус 200 OK буцаасныг curl-ийн бүтэн гаралтаар баримтжуулав. Ажигласан согогууд charter-ийн хүрээнд байв; урт гарчиг/зохиолч болон тусгай тэмдэгтийн layout-д үзүүлэх нөлөөг шалгаж амжаагүй. Дараагийн charter-д урт болон Unicode утга, whitespace, хайлтын тусгай тэмдэгт, байхгүй ID-г устгах зэрэгт төвлөрнө. Lab 1-ийн Playwright тестэд тохирох assertion байсан бол тоолуур, validation, давхардал, case-insensitive хайлт, жилийн хил, устгалын мессеж болон API статусын согогууд автоматаар илрэх боломжтой байв. Устгах товчны ногоон өнгө, оны таслалтай бичиглэл нь дэлгэцээс шууд анзаарагдсан боловч screenshot/CSS assertion-тай автомат тест мөн барьж чадна. Lab 1-ийн яг ямар assertion-ууд байсныг энэ session-д шалгаагүй тул автомат тестээр баригдах тухай ангилал нь таамаг юм.
