# BUG-07: “Хуучин хувилбар” холбоос Internal Server Error харуулна

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 154.0.8037.98, Windows, 2026-10-19
Урьдчилсан нөхцөл: `node app.js` ажиллаж, үндсэн хуудас нээлттэй.

## Дахин гаргах алхам
1. `http://localhost:3000` нээнэ.
2. Доод хэсгийн “Хуучин хувилбар” холбоосыг дарна.

Хүлээгдэж байсан: Холбоос ажиллаж, хуучин хувилбарын хуудас нээгдэнэ.
Бодит үр дүн: Хөтөч `/old` хаягт очиж, “Internal Server Error” харуулсан.

Ноцтой байдал: Major — харагдаж буй навигацийн холбоос хэрэглэгчийг алдааны хуудсанд хүргэнэ.
