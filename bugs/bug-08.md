# BUG-08: Буруу JSON POST хүсэлтэд 400 бус 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0, Node.js v22.14.0, Windows, 2026-10-19
Урьдчилсан нөхцөл: `node app.js` ажиллаж, `localhost:3000` сонсож байна.

## Дахин гаргах алхам
1. PowerShell нээнэ.
2. Дараах хүсэлтийг илгээнэ:

```powershell
curl.exe -i -X POST http://localhost:3000/api/books `
  -H "Content-Type: application/json" `
  --data-binary '{bad json'
```

Хүлээгдэж байсан: HTTP 400 алдааны статус буцаана.
Бодит үр дүн: `HTTP/1.1 200 OK` болон `{"result":"OK"}` буцаасан.

Ноцтой байдал: Major — амжилттай боловсруулаагүй хүсэлтийг амжилттай мэт буцааж байна.
Хавсралт: [curl -i бүтэн гаралт](../evidence/bug-14-curl.txt)
Олдсон аялал: Saboteur (API)


**Session-ээс хойших дахин шалгалт:** Тестер аппыг шинээр асааж тайлангийн bug-уудыг дахин шалгахад өмнөх зан төлөвүүд хэвээр байсныг мэдээлсэн. Дахин шалгалтад тусдаа screenshot аваагүй; эхний шалгалтын нотолгоог дээрх хавсралтаар ашиглана.
